# Find First and Last Position of Element in Sorted Array (LeetCode 34)

## 1. Intuition

The goal is to find the first and last occurrence of a target value in a sorted array.

The simplest approach is to scan the array from the beginning to find the first occurrence and then scan from the end to find the last occurrence. As soon as the target is found in each scan, we stop searching. If the target is not present, both positions remain `-1`.

### Why did I choose this approach?

- It is simple and easy to understand.
- It does not require any complex logic.
- It correctly finds both the first and last positions of the target.
- It works for all valid test cases.

---

## 2. Approach

### Algorithm

1. Initialize two variables:
   - `b = -1` to store the first occurrence.
   - `c = -1` to store the last occurrence.

2. Traverse the array from left to right.
   - If the target is found, store its index in `b` and stop the loop.

3. Traverse the array from right to left.
   - If the target is found, store its index in `c` and stop the loop.

4. Return `[b, c]`.

### Time Complexity

- **O(n)**

The array may be traversed twice, resulting in a total time complexity of **O(n)**.

### Space Complexity

- **O(1)**

Only two extra variables are used.

---

## 3. Code

```python
class Solution(object):
    def searchRange(self, nums, target):
        b = -1
        c = -1

        for i in range(len(nums)):
            if nums[i] == target:
                b = i
                break

        for j in range(len(nums) - 1, -1, -1):
            if nums[j] == target:
                c = j
                break

        return [b, c]
```

---

## Example

**Input**

```text
nums = [5,7,7,8,8,10]
target = 8
```

**Output**

```text
[3, 4]
```

**Explanation**

- The first occurrence of `8` is at index `3`.
- The last occurrence of `8` is at index `4`.
- Therefore, the returned result is `[3, 4]`.
