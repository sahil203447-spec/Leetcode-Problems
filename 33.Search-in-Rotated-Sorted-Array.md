# Search in Rotated Sorted Array (LeetCode 33)

## 1. Intuition

A normal Binary Search works only on a completely sorted array. In this problem, the array is sorted but rotated at an unknown index. However, one important observation is that **at least one half of the array is always sorted**.

The idea is to identify the sorted half during each iteration and determine whether the target lies within that range. If it does, continue searching in that half; otherwise, search the other half.

### Why did I choose this approach?

- It utilizes Binary Search, reducing the search space by half in every iteration.
- It efficiently handles the rotated sorted array without restoring or modifying the array.
- It achieves the required **O(log n)** time complexity.

---

## 2. Approach

### Algorithm

1. Initialize two pointers:
   - `s = 0` (start)
   - `e = len(nums) - 1` (end)

2. While `s <= e`:
   - Find the middle index:
     ```python
     mid = s + (e - s) // 2
     ```

3. If `nums[mid] == target`, return `mid`.

4. Check which half is sorted:
   - **Left half sorted** (`nums[s] <= nums[mid]`)
     - If the target lies between `nums[s]` and `nums[mid]`, search the left half.
     - Otherwise, search the right half.
   - **Right half sorted**
     - If the target lies between `nums[mid]` and `nums[e]`, search the right half.
     - Otherwise, search the left half.

5. If the target is not found after the loop, return `-1`.

### Time Complexity

- **O(log n)**

Since half of the search space is discarded in every iteration.

### Space Complexity

- **O(1)**

Only a few extra variables are used.

---

## 3. Code

```python
class Solution:
    def search(self, nums, target):
        s, e = 0, len(nums) - 1

        while s <= e:
            mid = s + (e - s) // 2

            if nums[mid] == target:
                return mid

            # Left half is sorted
            if nums[s] <= nums[mid]:
                if nums[s] <= target <= nums[mid]:
                    e = mid - 1
                else:
                    s = mid + 1

            # Right half is sorted
            else:
                if nums[mid] <= target <= nums[e]:
                    s = mid + 1
                else:
                    e = mid - 1

        return -1
```

## Example

**Input**

```text
nums = [4,5,6,7,0,1,2]
target = 0
```

**Output**

```text
4
```

**Explanation**

- The array is rotated.
- Binary Search identifies the sorted half in every iteration.
- The target `0` is found at index `4`.
